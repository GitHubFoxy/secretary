# Secretary

Персональный ассистент с постоянной перепиской и отдельными Workers для выполнения задач. Сервер сохраняет историю и состояние работы; веб-интерфейс позволяет общаться с Secretary и наблюдать за Workers.

Проект написан на Go. Веб-интерфейс использует Svelte.

## Запуск

```sh
./secretary setup
./secretary start
```

После setup команда доступна как `secretary` в `PATH`.

Подробности: [быстрый старт](docs/quickstart.md), [контракты системы](CONTEXT.md), [проверки](docs/phase3-release-gate.md).
