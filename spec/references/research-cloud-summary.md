Дата исследования: 2026-10-11. Исторические варианты и расчёты; это не требования тикета первой локальной интеграции. Фактическая API latency не измерялась, цены и model IDs перед использованием нужно перепроверить.

### Уточнение пользователя: локальный или облачный режим

Silero TE исключён по явному решению пользователя и больше не входит в shortlist. Пользователь хочет дать выбор: локальные ASR/форматирование при подходящем железе либо платный облачный режим для качества и низкой задержки. Ориентир «около $1/месяц» — гипотеза для расчёта при заданном usage, не утверждённый тариф и не обещание unlimited.

Следующее исследование сравнивает облачный ASR для **готового Telegram voice**, отдельно быстрый cloud formatter, совокупную стоимость, качество RU/EN, latency и обработку данных. Cloud credentials/API calls, реализация, установка и изменение omarchy не разрешены в рамках исследования.

### Рекомендация для следующего сравнения

**Первым integrated кандидатом взять ElevenLabs `scribe_v2` + `transcript_edit`.** Поддерживает RU/EN и готовые OGG, сохраняет оригинальную и отредактированную расшифровку. Публичный расход $0.22/h ASR + $0.07/h edit = $0.29/h. Edit экспериментальный, latency и semantic fidelity не измерены; $5 minimum PAYG top-up отличается от месячного расхода. Это лучший старт исследования качества/простоты, не объявление универсального победителя.

**AssemblyAI Dictation — integrated challenger для коротких сообщений.** RU/EN, raw `text` + cleaned `llm_response`, $0.62/h all-in, до 120 секунд, вход WAV/PCM. Для Telegram нужна decode/upload конвертация. При rewrite timeout сервис может вернуть HTTP 200 с raw и `llm_error`; успех HTTP не означает успешное форматирование. Рекламные ~134 ms p50 относятся к другому Sync endpoint без cleanup, не к нашему полному пути.

**Раздельная качественная связка:** OpenAI `gpt-transcribe` ($0.0045/min) + `gpt-6-luna` с reasoning `none`. Один аккаунт удобен, но это два последовательных запроса. **Экономичный вариант:** Groq `whisper-large-v3-turbo` ($0.04/h, minimum 10 секунд на запрос) + тот же небольшой formatter либо другой прошедший preservation tests. Soniox `stt-async-v5` (~$0.10/h по token-based оценке) — дополнительный balanced кандидат.

Для отдельного formatter сравнить **GPT-6 Luna `none`**, **Cerebras Qwen3.8-27B `none`** и **Gemini 3.5 Flash-Lite `minimal`**. Cerebras заявляет ~1850 output tokens/s, но это не p95 полного ответа; его тариф отмечен предварительным из-за динамической pricing page. GPT-4.1 mini с Predicted Outputs — контроль для косметических изменений почти неизменного transcript. У reasoning моделей обязательно проверить фактическую поддержку отключения; `minimal/low` не всегда означает ноль hidden tokens.

### Пример переменного расхода на 100 минут/месяц

Допущения formatter: 100 записей по минуте, 150 слов/мин, 200 transcript input/output tokens/мин и 100 instruction tokens/request. RU чувствительность: 1.5–2× transcript/output tokens. Это оценка, не измерение tokenizer.

- Scribe v2 + edit: **около $0.483**, без отдельного LLM.
- AssemblyAI Dictation: **около $1.033**, cleanup включён.
- OpenAI gpt-transcribe + Luna: **около $0.463 EN / $0.469–0.475 RU**.
- Groq Whisper Turbo + Luna: **около $0.080 EN / $0.086–0.092 RU**, если записи не увеличиваются minimum billing.

В отчётах есть расчёты на 30/100/300/1000 минут. Форматирование отдельно стоит центы; основная переменная цена обычно ASR. Множество 3-секундных сообщений оплачивается иначе, чем эквивалентный суммарный длинный файл. Retries, налоги, инфраструктура, поддержка, платежи, margin и стартовые пополнения здесь не включены. Около $1 может покрывать умеренный usage, но это не утверждённая цена подписки и не unlimited.

### Почему fastest пока не установлен

Готовый Telegram voice становится доступен боту после Send; MP3 не обязателен, обычно OGG/Opus. Источники подтверждают cloud Willow и вероятный **Wispr Flow**, но не точную streaming реализацию или публичный integration API этих приложений. Их monthly subscription не является тарифом используемых внутри speech/LLM API.

Нужен единый p50/p95 после Telegram Send: download → optional decode → upload → ASR final → formatter final → checks → Secretary/Worker. TTFT, realtime 150 ms, H200 throughput и output tokens/s описывают разные части; они не доказывают низкую полную задержку. Integrated API экономит внешний сетевой обмен, но не обязательно внутреннюю генерацию. Сравнить 5/15/60/120/300 секунд RU/EN/mixed из региона пользователей, cold/warm connections и concurrency.

### Выбор пользователя и обработка данных

В UX предусмотреть полностью локальный режим при достаточном hardware, полностью облачный с оплатой usage и при необходимости hybrid local ASR + cloud formatter. Hybrid отправляет transcript и не является полностью локальным. Telegram уже участвует в хранении/доставке оригинального voice независимо от выбора ASR.

Privacy проверять **по каждой стадии и endpoint**: текущая OpenAI таблица retention для audio transcriptions отличается от text formatter; Soniox async хранит файлы/результат до удаления либо срока, ElevenLabs ZRM — Enterprise, дешёвый тариф сам по себе не означает zero retention. Не переносить режим приватности Willow/Wispr на наш собственный provider pipeline.

ASR benchmark не выбирает безопасный cleanup автоматически. Хранить raw+formatted, проверить имена/числа/отрицания/команды, не разрешать tools formatter и при невалидном результате/timeout возвращать raw. Удаление fillers/самоисправлений — отдельный выбранный режим. Окончательный default выбирать после проверки этих требований и полной задержки, а не только красивого текста.

Никакие API/inference и загрузки моделей не выполнялись. На omarchy и в исходном коде изменений нет. В рамках этой работы обновлены только исследовательские документы и задача.
