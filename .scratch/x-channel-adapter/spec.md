# X Channel adapter

## Цель

Владелец может упомянуть `@SCRTRBOT` в X, получить ответ Secretary в публичной ветке исходного поста и продолжить пользоваться той же Personal Conversation, что и в остальных подключённых каналах.

## Принятые границы MVP

- Подключается один настроенный X-аккаунт Secretary и один разрешённый X-аккаунт владельца. Упоминания других авторов игнорируются: сервер пока поддерживает одну Personal Conversation одного Person.
- Ответы публикуются в X и видны всем, кто может читать исходную ветку. В X не отправляются входящие сообщения и ответы из других Channel adapters.
- X turn помечен как публичный: model context не включает записи из других каналов и приватные файлы/Workspace. Worker в MVP не запускается, поскольку его инструменты имеют доступ к локальному Workspace. Если запрос требует приватной информации, Secretary предлагает продолжить его в приватном канале.
- Вход — текстовые посты, содержащие явное упоминание настроенного `@SCRTRBOT`. Вложения, личные сообщения X, поиск произвольных постов и управление Worker из X не входят в MVP.
- Адаптер читает ленту упоминаний через X API polling с сохранённым cursor и deduplication по ID поста. Восстановление ограничено последними 800 упоминаниями, которые предоставляет X; выход cursor за это окно явно показывается владельцу.
- Входной пост сохраняется в серверной Personal Conversation с внешним ID, а ответ сохраняет связь с конкретным исходным постом. Повторное чтение не создаёт второй Conversation entry и не публикует второй ответ.
- На одно пользовательское X interaction публикуется не более одного автоматического reply: один итоговый текст Secretary. Длинный ответ не разбивается на серию постов.
- Владелец может явно остановить автоматические ответы и включить их снова. Состояние opt-out переживает restart.
- Сохранённые X posts синхронизируются с их актуальным состоянием на X. Удаление/изменение, переход в protected/private, suspension/withholding прекращают использование контента. Прямой запрос X или владельца запускает немедленную очистку; все копии удаляются максимум за 24 часа с получения запроса.
- Секреты X хранятся отдельно от публичного состояния Channel adapter. Интеграция выключена, пока явно не настроена. Любые реальные AI replies, даже тестовые, заблокированы до письменного явного одобрения X и отдельного конфигурационного подтверждения этого одобрения; перед запуском также требуются включённый `Automated` label, указание оператора в bio и связь с человеческим аккаунтом.

## Вне цели

DM, обработка упоминаний сторонних пользователей, отдельные Conversations на автора, автоматическая OAuth-авторизация через UI, медиа, публичная лента/поиск, реакции и X Activity/webhook delivery.
