# 01: Убрать незапрошенные URL; запрошенные ссылки оформлять в Markdown

Type: task
Status: needs-triage
Blocked by: None

## Что сделать

Реализовать [спецификацию](../spec.md) для ответов Secretary и Worker. По умолчанию исключить URL, включая citations, proof и source links. При явном запросе ссылки использовать Markdown с коротким названием и без сырого URL; отключить Telegram link preview.

Текущий `internal/config/defaults/worker.md` просит возвращать «any essential evidence or source». Уточнить это правило, сохранив проверку источников и честность отчёта, но исключив незапрошенные ссылки.

## Критерии приёмки

- [ ] Обычные ответы Secretary и Worker, включая результаты поиска и отчёты с доказательствами, не содержат незапрошенных URL или Markdown-ссылок.
- [ ] На явный запрос URL/ссылки ответ содержит `[название](URL)`, без сырого URL в видимом тексте.
- [ ] Запрошенные ссылки корректно проходят Telegram formatting/splitting и отображаются кликабельными названиями без link preview.
- [ ] Проверка актуальных фактов, указание неопределённости и ограничения результата сохранены.
- [ ] История, исходный ввод, код и URL в необходимых технических материалах не повреждаются.
- [ ] Правило закреплено в profiles без дублирования в каждом Task prompt; документировано обновление фактически настроенных внешних profiles.
- [ ] Проверки покрывают обычный ответ с источниками, явный запрос ссылки и Telegram отправку; выполнена живая проверка обоих вариантов.

## Comments

Пользователь просит убрать URL, включая citations/proof/source, если URL явно не запрошен. Причина — громоздкое отображение в Telegram и preview. Для запрошенных URL пользователь требует Markdown, никогда сырой URL.
