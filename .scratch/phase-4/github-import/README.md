## Сохранённые данные

- `issue-N.json`: полный ответ GitHub API с описанием, автором, датами и metadata.
- `comments-N.json`: все страницы комментариев.
- `timeline-N.json`: все страницы timeline.
- `manifest.json`: соответствие номеров и SHA-256 исходных snapshots и описаний.

Snapshots являются историческими данными. Они намеренно сохраняют старые GitHub URL и состояние `open`, соответствующее моменту выгрузки. Для текущей работы использовать локальные тикеты, а не эти URL.
