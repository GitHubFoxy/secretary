# Проверка спецификации: длительность ASR и форматирования

Дата: 2026-10-11. База: `276aca40a30970b386079c3b0a5e8e8764213bda`. Проверены изменения `voice.go`, `voice_test.go`, новый `voice_timing_test.go`, эксплуатационная инструкция и комментарий тикета. Несвязанные изменения исключены. Код и production не менялись.

## Результат

Подтверждённых дефектов соответствия запросу пользователя «we need to track how much is take, for asr and formatter» не найдено.

- Download, ASR и formatter измеряются отдельными `time.Now` / `time.Since`, использующими монотонную часть времени. Запись ASR окружает весь `Transcribe`: ожидание локального слота, conversion, model load и inference входят в значение.
- Успешная расшифровка сохраняет миллисекунды всех стадий и фиксированный статус форматтера. При ошибке форматтера сохраняется измеренная длительность с raw fallback; при отключённом/отсутствующем форматтере длительность равна нулю и статус различает причины.
- Processing завершается до сохранения state, Telegram notices и dispatch. Новый тест проверяет наличие окончательных метрик перед dispatch; повтор после restart, включая неудачную первую доставку, использует сохранённые значения без повторного ASR/formatter.
- Ошибки download/ASR имеют журналирование длительности без создания успешного transcript. Журнал содержит только числовые identity, длительности и фиксированные статусы; ошибки, transcript, file ID и audio не включаются.
- `timing` — optional pointer: старые записи сохраняют отсутствие измерения (`nil`), а не получают ложный ноль. Новый код не меняет настройки formatter и не включает его автоматически.

Изучены успешные логи полного Go suite и race Telegram/config; scoped diff-check успешен. Повторные тесты и SSH-команды этим reviewer не выполнялись.

## Границы измерения

Показатель ASR описывает полный вызов, не чистый inference. Processing не включает предыдущую очередь входа topic, действия агента и Telegram response. Эти границы явно описаны в документации. Живая проверка новых полей на production остаётся задачей deployment/приёмки, а не доказанной этим review.
