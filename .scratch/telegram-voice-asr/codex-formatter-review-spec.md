# Проверка спецификации: форматтер через подписку Codex

Дата: 2026-10-11. База: `1f7f58f`; проверены текущие изменения замены транспорта и новый `internal/telegram/formatter_process_test.go`. Несвязанные изменения пользователя исключены. Код и production не изменялись.

## Результат

Подтверждённых дефектов соответствия спецификации не найдено.

- Требование «API-ключи не используются»: HTTP/API транспорт удалён, схема требует `provider: codex`, obsolete `api_key_env` отклоняется строгим YAML-парсером. Formatter исключает `OPENAI_API_KEY` и `CODEX_API_KEY` из окружения и задаёт `forced_login_method="chatgpt"`.
- Требование «GPT-6 Luna, reasoning: none; никакой подмены модели»: выбранная модель передаётся непосредственно через `-m`; CLI получает `model_reasoning_effort="none"`. Несовместимость/ошибка дают raw fallback, альтернативный model ID не выбирается.
- Требование отдельного промпта и transcript как данных: инструкции записываются в приватный временный файл, `model_instructions_file` передаётся как путь; JSON transcript находится в stdin. В args отсутствуют transcript и содержимое промпта. Отдельный cwd, ephemeral, игнорирование config/rules/project docs и отключение функций соответствуют текущему контракту.
- Требование отказа при tool/action/reasoning output: JSON allowlist отвергает соответствующие события, неизвестные события, malformed/incomplete output и ненулевой счётчик reasoning. Консервативные текстовые guards сохранены без изменения; существующий voice pipeline использует raw с уведомлением при ошибке.
- Тайм-аут ограничивает CLI, включая wrapper и дочерний процесс через существующую process group cancellation. Временные инструкции и output удаляются после завершения процедуры остановки. Новый реальный subprocess regression проверяет прекращение heartbeat и очистку.

Сопоставлены config/adapter/formatter, все изменённые тесты, пример конфигурации, инструкция и обновлённые spec/ticket. Проверены сохранённые результаты полного Go suite и race Telegram/config: оба успешны; дополнительных повторных запусков не делалось.

## Границы приёмки

Родитель сообщил успешный настоящий Go formatter smoke на omarchy, 9,048 секунды. Это подтверждает транспорт через подписку, но не заменяет пользовательский Telegram E2E. RU/EN voice → Secretary/Worker и актуальный production deployment ещё требуют финальной приёмки; открытый статус тикета соответствует этому ограничению. Смысловая сохранность остаётся документированной эвристикой, а не гарантией.
