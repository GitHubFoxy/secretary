# Похожие проекты для сайта Secretary

Проверено 12 ноября 2026 года по описаниям и документации проектов. Продукты не устанавливались и не тестировались. Русскоязычная документация не подтверждает российское происхождение проекта.

Secretary объединяет длительную переписку с делегированием задач воркерам на подключённых машинах. Подробное сравнение архитектуры и пользовательских сценариев находится в [обзоре персональных агентов](./README.md).

## Близкие аналоги

- [OpenClaw](https://openclaw.ai/) — персональный ассистент, который запускается на своей машине и подключается к мессенджерам. Для сайта Secretary полезен как пример объяснения возможностей через повседневные задачи. Подробнее: [исследование OpenClaw](./openclaw.md).
- [Hermes Agent](https://hermes-agent.nousresearch.com/) — персональный агент с постоянной памятью, субагентами и подключением мессенджеров. Его [память](https://hermes-agent.nousresearch.com/docs/user-guide/features/memory/) сохраняется между сессиями. Подробнее: [исследование Hermes](./hermes.md).
- [Bender](https://github.com/0717376/bender/blob/main/README.ru.md) — личный агент на своём оборудовании с долговременной памятью, заметками, задачами и Telegram. Поддерживает Claude Agent SDK или Codex SDK. Есть русскоязычная документация.
- [CORE](https://git.mitgai.net/RedPlanetHQ/core) — персональный ассистент с памятью, рабочими интеграциями и фоновым запуском Claude Code или Codex. Проект полезен для сравнения работы с контекстом из разных источников.
- [Svoi](https://github.com/Zazza/svoi-oss) — самостоятельно размещаемый ассистент на Go с чатом, инструментами, памятью, базой знаний и напоминаниями.
- [KiroCrew](https://habr.com/ru/articles/1078482/) — агент с памятью, фоновыми субагентами и доступом через браузер или настольный клиент. Ссылка ведёт на русскоязычный обзор; сведения о проекте здесь основаны на этом обзоре.
- [Letta](https://docs.letta.com/concepts/stateful-agents) — платформа для агентов с сохраняемой памятью, историей и настройками. Полезна для сравнения подходов к постоянной идентичности агента. Подробнее: [исследование Letta](./letta.md).

## Соседний проект для разработки

[T3 Code](https://t3.codes/) — открытая платформа управления coding-агентами. Она объединяет потоки работы, ветки и удалённые среды. Пересечение с Secretary заметно в делегировании и работе с несколькими машинами, хотя T3 Code ориентирован на разработку. Источники: [удалённый доступ](https://github.com/pingdotgg/t3code/blob/main/docs/user/remote-access.md), [работа агентов с T3](https://github.com/pingdotgg/t3code/blob/main/docs/user/outside-agents.md). Подробнее: [исследование T3 Code](./t3-code.md).

## Направление для сайта

OpenClaw и Hermes полезно изучить как примеры подачи персонального ассистента, Bender — как русскоязычное описание близкого продукта, а T3 Code — как пример представления работы агентов. Для Secretary можно выделить единый разговор и делегирование задач на подключённые машины, не утверждая, что эти возможности уникальны.
