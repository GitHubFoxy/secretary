# Secretary

## Language

**Secretary App**:
Весь продукт, который мы строим: приложение на телефоне, сайт, сервер и всё, что работает вокруг агентов.
_Avoid_: Secretary (без уточнения), платформа, система

**Owner**:
Человек, которому принадлежат Host, Secretary Agent и Specialists, и единственный, кто разговаривает с Secretary Agent. У каждого Host ровно один Owner.
_Avoid_: пользователь, клиент, user

**Secretary Agent**:
Личный ИИ-помощник владельца, его правая рука и единственный агент, с которым владелец ведёт общение. Отвечает сам на то, что может сделать быстро, поручает работу Specialists, следит за её выполнением и сообщает важное.
_Avoid_: руководитель, chief of agents, роутер, оркестратор

**Specialist**:
Постоянная личность, которой Secretary Agent поручает работу одного направления: проект, покупки на Ozon и т. п. Живёт в своей папке, имеет свои память, навыки и сессии harness. Если папка Specialist — репозиторий, это проект.
_Avoid_: Chief of project, bot, profile, persona, worker, subagent

**Secretary Persona**:
Инструкции, характер и навыки Secretary Agent — то, что определяет, кто он. Лежит в папке `~/.secretary`. Secretary App поставляет Persona по умолчанию, дальше Owner меняет её как хочет.
_Avoid_: Secretary Agent Folder, шаблон, профиль, home folder

**Host**:
Машина, на которой работают harness: свой сервер владельца или облачный контейнер. На ней же работает программа Secretary и хранится состояние.
_Avoid_: нода, воркер, сервер

**Session**:
Любой работающий агент: процесс harness (Claude Code или Codex) плюс его история в SQLite. Secretary Agent и дочерние агенты — одинаковые сессии; у дочерней есть родитель.
_Avoid_: task, worker, тред, процесс

**Immediate message**:
Сообщение, которое прерывает текущий ход Session и отправляется сразу; когда Session находится в состоянии `idle`, отправляется как обычное сообщение.
_Avoid_: steer (вмешательство в ход без прерывания — это другое)
