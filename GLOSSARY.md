# Secretary

## Language

**Secretary App**:
Весь продукт, который мы строим: приложение на телефоне, сайт, сервер и всё, что работает вокруг агентов.
_Avoid_: Secretary (без уточнения), платформа, система

**Owner**:
Человек, которому принадлежат Host, Secretary Agent и Specialists, и единственный, кто разговаривает с Secretary Agent. У каждого Host ровно один Owner.
_Avoid_: пользователь, клиент, user

**Secretary Agent**:
Личный ИИ-помощник владельца, его правая рука и единственный агент, с которым владелец ведёт общение. Отвечает сам на то, что может сделать быстро, поручает работу Specialists, следит за её выполнением и сообщает важное.
_Avoid_: руководитель, chief of agents, роутер, оркестратор

**Specialist**:
Агент, который отвечает за одно направление целиком, обычно за проект. Сам распараллеливает работу в своей папке через Workers и единственный отчитывается Secretary Agent.
_Avoid_: Chief of project, bot, profile, persona, subagent

**Worker**:
Дочерняя Session, которую запускает Specialist для конкретной задачи (например, реализация фичи в отдельном git worktree или ревью). Не имеет доступа к MCP и отчитывается только своему Specialist.
_Avoid_: subagent, дочерний процесс, агент-исполнитель

**Secretary Persona**:
Инструкции, характер и навыки Secretary Agent — то, что определяет, кто он. Лежит в папке `~/.secretary`. Secretary App поставляет Persona по умолчанию, дальше Owner меняет её как хочет.
_Avoid_: Secretary Agent Folder, шаблон, профиль, home folder

**Host**:
Изолированное окружение одного Owner, где работают его Secretary и harness и хранится его состояние: контейнер на хостинге или собственная машина Owner.
_Avoid_: нода, воркер, сервер, машина

**Gateway**:
Единственная точка входа хостинга (`app.scrtrbot.ru`). Узнаёт Owner по устройству и ведёт его к его Host.
_Avoid_: proxy, router, балансировщик

**Номер аккаунта**:
Анонимный идентификатор Owner на хостинге, одновременно логин и пароль. Без почты и телефона.
_Avoid_: логин, ID пользователя, код сопряжения

**Session**:
Любой работающий агент: процесс harness (Claude Code или Codex) плюс его история в SQLite. Secretary Agent, Specialists и Workers — одинаковые сессии; у дочерней есть родитель.
_Avoid_: task, тред, процесс

**Immediate message**:
Сообщение, которое прерывает текущий ход Session и отправляется сразу; когда Session находится в состоянии `idle`, отправляется как обычное сообщение.
_Avoid_: steer (вмешательство в ход без прерывания — это другое)
