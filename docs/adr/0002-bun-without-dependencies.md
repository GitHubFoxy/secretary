# 0002. Bun как среда выполнения, без npm-зависимостей на сервере

Статус: принято 15 ноября 2026 года. Причины в обсуждении не записали; ниже они восстановлены по коду.

## Контекст

Серверу нужны HTTP, WebSocket, SQLite, запуск дочерних процессов и тесты. Прошлая версия проекта утонула в объёме кода, поэтому важно, чтобы зависимостей и кода было как можно меньше.

## Решение

Сервер работает на Bun и использует только встроенное: `Bun.serve` (HTTP и WebSocket), `bun:sqlite`, `Bun.spawn`, `bun:test`. В `server/package.json` нет зависимостей. MCP-сервер написан вручную (около 10 строк), без SDK.

## Последствия

- Нечего обновлять и нечему ломаться при установке; запуск — `bun index.ts`.
- Код завязан на API Bun. Переезд на Node.js потребует заменить сервер, SQLite и запуск процессов.
