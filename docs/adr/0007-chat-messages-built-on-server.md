# 0007. Сообщения чата строит сервер

Статус: принято 19 ноября 2026 года (PR #36).

## Контекст

В SQLite хранятся сырые события harness: Claude Code `stream-json` и уведомления Codex `app-server`. Раньше их разбирали четыре места, включая клиент: фильтр истории, `App.svelte`, `messages.js` и поиск последнего ответа в `Session`. Клиент получал поток всех событий всех сессий.

## Решение

`server/chat.ts` превращает событие в сообщение чата (`user`, `agent`, `report`, `error`, `cancelled`, `uncertain`) или отбрасывает его. Там же создаётся и разбирается формат отчёта `[report …]`. Сервер отправляет клиенту только сообщения чата, очередь, результаты прерываний и список сессий при смене статуса.

## Последствия

- Новый harness или новое событие меняют один файл.
- Клиент получает меньше данных и не знает протоколов harness.
- Агентам по-прежнему доступна полная история через MCP `read`.
