# 0001. Весь стек на TypeScript

Статус: принято 15 ноября 2026 года.

## Контекст

Первая версия Secretary была написана на Go: около 58 тыс. строк кода и 80 тыс. строк тестов, 2500 коммитов. До релиза она не дошла. Новый сценарий требует клиента на телефоне (PWA и Capacitor) и, позже, облачной части на Cloudflare. И то и другое пишется на TypeScript.

## Решение

Сервер пишем на TypeScript, клиент — на JavaScript со Svelte. Отдельный язык для сервера не используем.

## Последствия

- Один язык и одна экосистема на сервере, клиенте и в будущей облачной части. Типы протокола Codex генерируются прямо в TypeScript (`codex app-server generate-ts`).
- Клиент пока на JavaScript без проверки типов. Если клиент вырастет, перевод на TypeScript — отдельное решение.
