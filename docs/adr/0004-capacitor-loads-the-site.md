# 0004. Android-приложение — оболочка Capacitor, которая загружает сайт

Статус: принято 18 ноября 2026 года.

## Контекст

Нужно Android-приложение, которое открывается удержанием кнопки Power. Это требует нативного `VoiceInteractionService`: одна PWA роль системного помощника получить не может. Переписывать интерфейс нативно не хочется. Expo потребовал бы React Native.

## Решение

Capacitor с `server.url = https://app.scrtrbot.ru`: приложение — нативная оболочка вокруг сайта, который раздаёт сервер Secretary. Нативный код только для API телефона.

## Последствия

- Новая версия интерфейса доходит до телефона сразу после публикации сборки. Переустанавливать APK нужно только при изменениях нативной части.
- Без сети приложение пустое. Офлайн-режим не нужен: без сервера агент всё равно не ответит.
- Адрес сервера зашит в сборку. Для других пользователей понадобится выбор сервера или общий вход.
- Google Play может не принять приложение, которое только показывает сайт. Нативные функции помощника, голос и экран, снижают этот риск.
