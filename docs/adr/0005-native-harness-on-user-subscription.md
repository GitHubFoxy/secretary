# 0005. Работа идёт в нативном harness по подписке пользователя

Статус: принято 15 ноября 2026 года.

## Контекст

Claude Code и Codex уже умеют рассуждать, пользоваться инструментами и навыками. У пользователей уже есть подписки. Своя модель и свои API-ключи сделали бы продукт дороже и хуже.

## Решение

Secretary не содержит своей модели. Каждая Session — процесс Claude Code или Codex, вошедший подпиской пользователя. Secretary владеет разговором, очередью, историей и делегированием, а harness — рассуждением, инструментами и правами.

## Последствия

- Качество агентов растёт вместе с harness без нашей работы.
- Смена модели внутри harness сохраняет контекст. Смена harness начинает новую сессию.
- Правила подписок — внешний риск. На ноябрь 2026 года OpenAI разрешает «Sign in with ChatGPT» в сторонних приложениях (хостинговым продуктам нужна заявка). Anthropic запрещает использовать подписки Claude в сторонних продуктах без одобрения. Поэтому облачные контейнеры для других пользователей начинаем с Codex, а Claude поддерживаем там, где пользователь сам запускает harness на своём сервере. Перед запуском условия нужно перепроверить.
