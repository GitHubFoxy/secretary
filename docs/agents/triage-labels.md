# Triage labels

Engineering skills используют пять canonical triage roles. Этот файл сопоставляет их labels в данном repo.

| Label в mattpocock/skills | Label в этом tracker | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer должен оценить issue. |
| `needs-info` | `needs-info` | Нужны дополнительные сведения от автора. |
| `ready-for-agent` | `ready-for-agent` | Задача полностью определена и готова для AFK agent. |
| `ready-for-human` | `ready-for-human` | Нужна реализация или решение человека. |
| `wontfix` | `wontfix` | Задача не будет выполняться. |

Когда skill упоминает роль, использовать label из второго столбца. Если словарь когда-либо изменится, редактировать второй столбец.
