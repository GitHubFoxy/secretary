◈ 1. Разделение мозга и рук

Secretary (Daemon) — это мозг: он помнит ваши заметки (Obsidian), диету, историю задач и общается с вами. Ему не нужны гигабайты памяти. В Cloudflare Durable Object он стоит буквально копейки.

❖ 2. Локальные подписки и ACP

Когда ваш Макбук онлайн, нода `secretary-node` на Go задействует локальные подписки (Claude Code CLI / Codex / Antigravity). Вы платите $0 за токены API, пользуясь безлимитом подписок.

★ 3. Железный MicroVM Fallback

Ноутбук захлопнут? Сервер выключен? Secretary в облаке никогда не выдаст ошибку «Nodes offline». Он просто вызовет MicroVM (Firecracker) на 90 секунд, сделает коммит и выключит машину.
