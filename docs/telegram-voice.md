# Голосовые сообщения Telegram

Основная конфигурация Secretary остаётся `config.toml`. Настройки распознавания читаются из отдельного `config.yaml` рядом с ней: скопируйте `config.example.yaml`, укажите доступные веса Parakeet Q8 и положите рядом `formatter.md` из этой папки. Относительные пути к весам и промпту разрешаются от папки конфигурации.

На сервере необходимы `ffmpeg` и `nemo-speech` (в PATH; на omarchy используется существующий `/home/coder/.local/bin/nemo-speech`). Для форматирования используется установленный Codex CLI и существующая подписочная авторизация (`codex login`), `provider: codex`; API-ключи не нужны и не используются. Путь к CLI берётся из `SECRETARY_CODEX_COMMAND`, затем `CODEX_PATH`, затем PATH. Отказ подписочной авторизации не блокирует ASR: используется исходный текст с уведомлением. Старое поле `api_key_env` отклоняется.

После изменений YAML/промпта перезапустите Secretary: Telegram adapter использует настройки, загруженные при старте. `formatter.enabled: false` отключает облачное форматирование; `show_asr_in_chat: true` показывает итоговый текст ответом на исходное voice. По умолчанию отдельная расшифровка не публикуется.

Поддерживается только Telegram voice, локальный `nemo-speech` CPU с выбранным Parakeet GGUF и форматтер Codex по подписке. До download проверяются владелец/topic и известные лимиты; фактические размер и decoded WAV-длительность также ограничены. Voice и text сохраняют порядок внутри topic, другие topics обрабатываются независимо. Одновременно запускается один ASR.

Raw, успешный formatted и исходная Telegram identity сохраняются в приватном Telegram state. Форматтер запускает GPT-6 Luna none в Codex CLI; получает инструкции через временный `model_instructions_file`, transcript только через stdin JSON. API-key env не передаётся, login принудительно ChatGPT. Аудио не передаётся облачному форматтеру. Пользовательский config/rules и project docs отключены; отдельный cwd и ephemeral запуск не используют историю. CLI execution/integration features отключены, sandbox read-only, неожиданные tool/action/reasoning events отклоняют результат. Ошибка ASR сообщает о неудаче и освобождает очередь; ошибка/невалидный результат форматтера возвращает raw.

Проверка сохранности текста консервативная и не гарантирует полной смысловой эквивалентности. Тайм-ауты — ограничения ожидания, не обещание скорости. ENV threads=2 не является жёстким ограничением CPU/RAM; при необходимости администратор ограничивает сервис средствами systemd.
