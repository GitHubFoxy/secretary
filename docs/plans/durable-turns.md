# Продолжение хода после перезапуска

При загрузке работавшая Session получает статус `interrupted`.
Сообщения в полёте очередь по-прежнему отмечает `delivery_uncertain`.
При наличии `harness_session_id` в очередь добавляется служебная просьба продолжить работу.
`resumePending()` запускает её после готовности адаптеров: Claude использует `--resume`, Codex — `thread/resume`.
Служебное сообщение сохраняется отдельно и не показывается в чате как сообщение Owner.
Без идентификатора harness Session остаётся `interrupted`.
Практическая проверка harness пропущена по просьбе Owner.
